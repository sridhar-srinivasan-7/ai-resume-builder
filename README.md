# AI Resume Builder

AI-powered resume builder for students to create professional, ATS-friendly resumes quickly and efficiently.

## Features
- ATS-friendly resume templates
- AI-generated resume suggestions
- Easy customization
- Downloadable resume formats

## Tech Stack
- HTML
- CSS
- JavaScript
- Python / AI APIs (if used)

## Purpose
Built to help students create clean professional resumes for internships and placements.
